**Estruturas de Dados - Trabalho Final**

Considere um estacionamento de veículos com capacidade para até 8 veículos. É um estacionamento de formato retangular, limitado por duas ruas, como mostra a figura abaixo. Não é possível estacionar dois veículos um do lado do outro porque o espaço não comporta isso.

<img width="772" height="125" alt="image" src="https://github.com/user-attachments/assets/f5461f6a-308f-4779-b400-a3af2955959f" />

Você irá escolher uma estrutura de dados adequada para armazenar os dados dos veículos, como Placa, Nome, Marca, Hora de Entrada e Hora de Saída, por exemplo.

O programa deverá conter, dentre outros, alguns métodos específicos:

1. Entrar com um veículo no estacionamento, desde que exista vaga disponível;
2. Retirar um veículo do estacionamento. Nesse caso poderá existir necessidade da retirada e reentrada de um ou mais veículos até que o veículo em questão possa ser retirado;
3. Pagamento do estacionamento. Quando o veículo entra o horário de chegada é computado e quando sai o horário de saída também é registrado. O estacionamento cobra R$ 12,00 por hora, inteira ou fracionada (ex.: se o veículo ficou 2:40 h no pátio paga no total R$ 36,00).
4. Listagem de todos os veículos do pátio.
5. É obrigatório o uso de ponteiros.
